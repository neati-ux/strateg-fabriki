# Испытания моделей

Одна зафиксированная версия агента и одинаковая копия кейса для всех участников. Провайдер и модель — разные поля: записать точный ID, версию среды, дату, доступные инструменты, лимит контекста (если известен) и ручную помощь.

Подготовка: `python tools/strateg.py trials init --output benchmarks/2026-11-18 --case test-brief-4`.

В каждой из пяти папок сначала NOT_RUN. Отчёт о модели не считается испытанием до запуска. Для Cursor проверяется выбранная доступная модель; web chat фиксируется как другая среда. Нельзя приписывать чату возможность выполнять команды, если у него нет терминала.

Запустить одинаковый бриф в чистом проекте. Ответы человека на развилках фиксировать дословно. Сохранить outputs, реестры, журнал, проверки и ошибки. Перерыв/продолжение и поправку исходного факта проводить одинаково. Обычный чат получает те же материалы, вопрос и бюджет; сравнение частей процесса не называть сравнением полного пути.

Регистрация: `python tools/strateg.py trials record --run benchmarks/2026-11-18/claude --model EXACT_ID --environment Cursor --evidence PATH --status completed --note TEXT`. Статус completed подтверждает сохранение артефактов, не качество ответа. Для API указать billing и cost-usd; неизвестная цена не равна нулю. Подписку учитывать отдельно от эквивалента API.

Сводка: `python tools/strateg.py trials report --directory benchmarks/2026-11-18`.

Оценка отдельно от автора, по одинаковой рубрике 0–2: доказательность, содержательное различие вариантов, экономика с базой расчёта, честность обещаний, выполнимость следующего действия, реакция на поправку, продолжение после перерыва. К каждому баллу — пример из результата. Скрыть название модели от оценщика. Не приравнивать мнение модели-судьи к независимой экспертизе.
