ПРОВЕРКА АГЕНТА «СТРАТЕГ ФАБРИКИ ПРОДУКТОВ» В CODEX
Пошаговая инструкция. Займёт около двух часов.

КАК ЭТО УСТРОЕНО
Кодекс и есть проверяемый агент. Ты играешь руководителя продукта:
пишешь Кодексу фразы из этой инструкции по одной и смотришь,
правильно ли он себя ведёт. Отчёт заполняешь сам.

НЕ ДЕЛАЙ ТАК:
- не отдавай Кодексу эту инструкцию и не проси его «пройти проверку»;
- не проси Кодекс запустить команду codex — он уже Кодекс.


==================================================================
ЧАСТЬ 1. ПОДГОТОВКА (один раз)
==================================================================

Шаг 1. Распакуй архив strateg-fabriki.zip.
       Например, в C:\strateg-fabriki
       Внутри должны лежать файлы AGENTS.md, README.md и папки skills, tools.

Шаг 2. Почини песочницу Кодекса (иначе будет ошибка
       «Your Windows doesn't fully support CET»).
       1) Полностью закрой Codex.
       2) Нажми Win+R, вставь и нажми Enter:
          notepad %USERPROFILE%\.codex\config.toml
          Если Блокнот спросит, создать ли файл, — ответь «Да».
       3) Допиши в конец файла две строки:

          [windows]
          sandbox = "elevated"

          Если в файле уже есть строка prefer_mxc = true,
          замени true на false.
       4) Сохрани (Ctrl+S) и закрой Блокнот.

Шаг 3. Открой Codex.
       Открой папку C:\strateg-fabriki как проект (рабочую папку).
       Если Windows попросит права администратора для настройки
       песочницы — разреши.

Шаг 4. Проверь, что всё работает. Напиши в чат Кодекса:

       Выполни команду python tools/strateg.py -h и покажи результат.

       Должен появиться список команд (new, use, status, check...).
       - Снова ошибка CET: закрой Codex, в config.toml замени
         "elevated" на "unelevated", открой Codex снова и повтори шаг 4.
       - Всё равно ошибка: остановись и пришли номер сборки Windows
         (Win+R → winver) и файл
         %USERPROFILE%\.codex\.sandbox\sandbox.log

Шаг 5. Открой файл ОТЧЁТ-ПРОВЕРКИ.md в Блокноте — туда будешь
       записывать, что получилось на каждом шаге.
       Запиши время начала.
