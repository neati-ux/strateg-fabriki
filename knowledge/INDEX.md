# Методические знания: что где искать

Это справочник о том, как делать работу хорошо. Он не зависит от проекта. Читай только файл, нужный текущему шагу.

| Файл | О чём | На каком шаге |
|---|---|---|
| `evidence-rules.md` | типы утверждений, что считается источником, как писать тезисы | 3–7, обязательно |
| `jtbd.md` | как описать аудиторию через её задачу и альтернативы | 3, 5 |
| `interviews.md` | вопросы интервью, разбор ответов, модельные респонденты | 3 |
| `data-checks.md` | проверка таблиц перед расчётом, выбор метода | 2, 3 |
| `ux-review.md` | разбор интерфейсов и пользовательских путей по скриншотам | 2, 3 |
| `options.md` | как строить разные по сути варианты и сравнивать их | 4 |
| `product-strategy.md` | состав продуктовой стратегии, осознанные отказы, экономика | 5 |
| `comms-strategy.md` | барьер, ключевое сообщение, подтверждение, роль каналов | 5 |
| `verification-plan.md` | как проверять гипотезы: показатель, сравнение, срок, пороги | 6 |

Связи: `jtbd.md` → `product-strategy.md` (аудитория и альтернативы) → `comms-strategy.md` (барьер вытекает из альтернатив) → `verification-plan.md` (проверяем гипотезы обеих стратегий).

Поиск по смыслу: если не знаешь, в каком файле ответ, ищи по словам из первого столбца таблицы ниже.

| Если вопрос про… | Смотри |
|---|---|
| факт, гипотеза, прогноз, пробел, синтетика, ссылка на источник | `evidence-rules.md` |
| сегмент, потребность, конкуренты, чем пользуются сейчас | `jtbd.md` |
| отток, удержание, конверсия, когорты, среднее и медиана | `data-checks.md` |
| экран, сценарий, шаги до цели, что мешает в интерфейсе | `ux-review.md` |
| «оставить как есть», «закрыть», критерии сравнения | `options.md` |
| позиционирование, для кого не делаем, юнит-экономика | `product-strategy.md` |
| слоган, сообщение, каналы, обещание | `comms-strategy.md` |
| эксперимент, контрольная группа, метрика успеха | `verification-plan.md` |
