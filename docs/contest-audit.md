# Сверка с условиями от 18 ноября 2026 года

### Повторная приёмка перед записью

DeepSeek в OpenCode: отдельно проверены ответы по PDF, CSV, речи и визуальному коду в MP4. Контроль подмены дал 35/125 = 28%, инцидент записан в состояние школы. Расход основной сессии с тремя помощниками составил 0,122389 USD по журналу хоста. Метрика времени включает ожидание пользователя. Труд человека, поиск и монтаж учитывать отдельно. Эти измерения относятся к школе. Архив для съёмки исключает старые проекты и ключ оценки. Синтетические материалы eSIM подготовлены отдельно. Перед сдачей капитану проверить актуальный бриф в кабинете и доступ жюри. Готовые стратегии eSIM, обязательное видео, документ со скриншотами и ссылки для сдачи остаются открытыми.
