# Источники и медиа

`strateg fetch https://example.org --output projects/PROJECT/materials/web/page.md` сохраняет текст, исходный HTTP-ответ и метаданные. Команда не исполняет JavaScript, не входит в аккаунты и не обходит отказ сайта. Лимит 3 MiB, проверяются URL и перенаправления. Это не изолированный безопасный браузер: для недоверенных сетей нужна отдельная песочница; DNS-проверка перед запросом сама по себе не устраняет rebinding.

`strateg media --input interview.mp4 --output projects/PROJECT/materials/interview --model base` использует установленный faster-whisper и библиотека обработки медиа. Возможна загрузка весов модели. Зависимости не устанавливаются автоматически. Речь обрабатывается локально, внешние платные API не вызываются.

`--transcript result.json` принимает готовый JSON с segments: start, end (секунды), text. Формат результата хранит хеши записи и расшифровки, способ обработки и таймкоды. Команда не подтверждает соответствие готовой расшифровки записи: это проверяется отдельно. Распознавание речи не исследует визуальный ряд видео.

Зарегистрировать документ через source add с путём к transcript.md и примечанием о происхождении. Существенные цитаты сверить с оригиналом; автоматическая сверка текста не доказывает точность распознавания.

## Установка и кадры видео

На Windows: `python3 -m venv .venv-media`, затем `.venv-media/Scripts/python.exe -m pip install -r requirements-media.txt`. Команда media автоматически использует эту среду. PyAV закреплён на 18.1.0: версия 19 несовместима с текущим faster-whisper.

Для видео добавьте `--frames`: сохраняются до 12 равномерно выбранных кадров шириной 640 пикселей, их таймкоды и хеши. Агент должен отдельно открыть кадры доступным инструментом просмотра и описать увиденное. Выборка может пропустить короткое событие; для него нужен отдельный просмотр. Без просмотра нельзя утверждать, что видео понято. `--language ru` задаёт язык при неверном автоопределении.

Видео без речи: `--frames-only` извлекает кадры без запуска распознавания.

Медиазависимости требуют Python 3.11 или новее. На Linux/macOS среда использует `.venv-media/bin/python`. Основные команды агента от медиазависимостей не зависят.
