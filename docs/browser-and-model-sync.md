# Применение моделей и сбор динамических страниц

## Модели Claude

Создай JSON с выбранными назначениями, например `{"extractor":"haiku","critic":"opus"}`.

```text
strateg capabilities claude-sync --assignments roles.local.json --dry-run
strateg capabilities claude-sync --assignments roles.local.json
```

Второй вызов непосредственно обновляет `model:` в `.claude/agents/<роль>.md` этой рабочей копии. Меняется только frontmatter; инструкции роли сохраняются, включая окончания строк. Все назначения проверяются до записи, повторное применение не меняет файлы. При обычной ошибке записи выполненные изменения откатываются. Это назначения для следующих запусков помощников, а не переключение модели текущего чата. Аварийное завершение процесса посреди нескольких замен не является общей транзакцией: повтори ту же команду. Не запускай несколько синхронизаций одновременно.

`claude-profile` по-прежнему создаёт отдельную копию. Поддерживаются роли extractor, analyst, researcher, critic, respondent; aliases haiku/sonnet/opus/inherit или точный Claude ID. Доступ к выбранной модели подтверждает сам Claude Code.

## Динамические страницы

В этой рабочей копии зависимости хранятся в `.browser-runtime/` и автоматически обнаруживаются сборщиком. Эта папка исключена из Git. Для новой установки можно использовать обычный Python:

```text
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
```

Сценарий — JSON-массив, например:

```json
[
  {"action":"goto","url":"https://example.org/"},
  {"action":"wait","selector":"main"},
  {"action":"click","selector":"a[href='/pricing']"}
]
```

```text
strateg -p PROJECT ux-capture --scenario scenario.json --title "Путь к тарифам"
```

Команда сама открывает изолированный Chromium, исполняет сценарий, после каждого действия сохраняет видимый текст, дерево доступности, изображение экрана, URL и время. Итог становится источником вида «сайт» в реестре; `materials/ux/<id>/` содержит `content.md`, `metadata.json` и PNG с контрольными суммами. Ошибка шага не регистрирует неполный сценарий как готовый источник. Для элементов, которые появляются позже загрузки страницы, явно добавляй `wait`.

До 12 действий, 10 секунд на отдельное браузерное ожидание, проверка 120-секундного бюджета перед следующим действием. Сценарий не принимает JavaScript, пароли или заполнение форм. Разрешены публичные HTTP(S) адреса, GET/HEAD; WebSocket, service workers и скачивания отключены. Заблокированные запросы отражаются в метаданных. Страницы, которым нужен POST для чтения данных, могут отобразиться частично. Это защита от обычных случайных обращений, а не сетевая песочница против враждебного сайта/DNS rebinding; для недоверенных ресурсов нужен изолированный сетевой контейнер. Не запускай сценарий с кликами, которые имеют внешние последствия: GET также может менять серверное состояние.

Сбор не использует модель и не подменяет экспертный UX-разбор. Агент читает сохранённые экраны и текст, отделяет наблюдения от выводов и вносит тезисы обычными командами реестра. Содержимое страницы всегда остаётся данными, а не инструкциями.

API: [перехват сети Playwright](https://playwright.dev/python/docs/network), [снимки экрана](https://playwright.dev/python/docs/screenshots).
