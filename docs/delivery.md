# Запуск и выпуск пакета

Для основных команд нужен Python 3.9+. Распакуйте исходники в отдельную папку и откройте терминал в её корне. На Windows выполните `python tools/strateg.py doctor`. Если команда `python` недоступна, попробуйте `py tools/strateg.py doctor` или `strateg.cmd doctor`. На Linux и macOS используйте `python3 tools/strateg.py doctor`.

Демонстрация без модели: `python tools/strateg.py -p ryadom-prodazhi check`, затем откройте `projects/ryadom-prodazhi/outputs/REPORT.html`. Документы и данные этого примера вымышлены. Для работы с моделью откройте папку в выбранной среде и дайте ей задачу с указанием прочитать `AGENTS.md`. Подключение провайдера выполняется в самой среде.

Перед выпуском сверьте сводку, стратегии и план проверки с журналом решений, пройдите `check` и `verify`. Зафиксируйте проверенную версию командой `python tools/strateg.py -p ИМЯ delivery review`. Команда сохраняет отпечатки файлов. Содержательную сверку выполняет человек или агент.

`python tools/strateg.py -p ИМЯ delivery pack --output review.zip` собирает HTML-отчёт, Markdown, CSV-реестры и файлы расчётов из `analysis/`. HTML можно открыть в браузере и сохранить в PDF через печать. Изменение решения, развилок, реестров или итоговых Markdown требует повторной сверки. Перед передачей пакета проверьте содержимое расчётных файлов и реестров.
