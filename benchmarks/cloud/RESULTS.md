## Сравнение способов работы

Кейс о выдаче заказов в музее. Во всех трёх прогонах руководитель задавал одну и ту же задачу, затем сообщал, что случайно разделить посетителей по группам технически невозможно. Пять критериев зафиксированы до получения ответов. В обычном чате работала Qwen2.5-1.5B. В двух прогонах с ролями автор и критик использовали ту же модель. Вариант с маршрутизацией передавал анализ Qwen2.5-0.5B. [Протокол](protocol.md) · [Код](compare.py) · [Облачный прогон](https://github.com/neati-ux/strateg-fabriki/actions/runs/44878356478).

| Вариант | Критерии из 5 | Вызовы | Токены, вход и выход | Время с загрузкой весов |
|---|---:|---:|---:|---:|
| [Обычный чат](results/chat.json) | 0 | 2 | 1 373 | 50,3 с |
| [Все роли на 1.5B](results/single.json) | 1 | 4 | 8 505 | 336,0 с |
| [Аналитик на 0.5B](results/routed.json) | 1 | 4 | 8 505 | 300,0 с |

Оценка выставлена вручную по ответам для руководителя. Обычный чат считал заказы за 72 часа, упустив условие выдачи. Обе конфигурации с ролями воспроизвели метрику целиком. Ни одна из трёх записок не сообщила результат дедупликации (два из трёх), ограничение тематической выборки и выбор инструкций за 3 000 рублей с проверкой внутри площадок. Все три пропустили запрет случайного распределения при пересмотре решения.

У двух вариантов с ролями обе итоговые реплики достигли лимита в 600 выходных токенов. Вариант с одной моделью выдал число 0,333 без данных для расчёта. Вариант с маршрутом добавил даты, которых в задании не было. Такой ответ нельзя передавать директору без проверки.

За один прогон смена модели аналитика сократила время четырёх вызовов с 336 до 300 секунд (около 11%) при той же оценке 1/5. Для вывода о стабильной экономии нужны повторы. Самым быстрым оказался обычный чат. Запросов к платному модельному API было ноль. Стоимость виртуальной машины по счёту GitHub не измерялась. Реплики руководителя заданы заранее, поэтому длительность работы живого пользователя здесь неизвестна.

Эти результаты относятся к открытому семейству Qwen2.5 и указанным ограничениям генерации. Семь интерактивных шагов, полный цикл в Cursor, стоимость с участием человека и устойчивое превосходство над обычным чатом требуют отдельных измерений.
