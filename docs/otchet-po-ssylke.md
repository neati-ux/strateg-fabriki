# Публикация демонстрационного отчёта

1. Выбрать чистый демонстрационный проект с вымышленными либо публичными материалами.
2. Выполнить check, verify, report; разобраться с предупреждениями, а не скрывать их.
3. Проверить REPORT.html, ссылки на источники и отсутствие личных данных, ключей и локальных приватных путей.
4. Опубликовать исходники проекта и отчёт. GitHub показывает исходный HTML; для просмотра отчёта как страницы нужен GitHub Pages либо другой статический хостинг.
5. Проверить опубликованную ссылку без входа в аккаунт. До этого не отмечать публикацию завершённой.

В выпуск не включать projects/obzor-obsidian-agenta, журналы личных чатов, Vault, .env, usage приватных сеансов и кеши. ZIP — дополнительный файл релиза; исходники должны быть доступны отдельно.
