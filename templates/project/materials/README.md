# Материалы проекта

Положи сюда свои файлы: документы, таблицы, скриншоты, расшифровки интервью. Агент сам зарегистрирует их в `sources.csv`.

- `web/` — сохранённые копии веб-страниц с адресом и датой обращения. Нужны, чтобы тезис можно было проверить, даже если страница изменится.
- `interviews/` — расшифровки. Модельные интервью лежат в файлах с именем `synthetic-…` и пометкой «СИНТЕТИКА» в первой строке.

Только открытые данные и собственные материалы. Без персональных данных: вместо имён роли.
