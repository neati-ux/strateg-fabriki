# Claude Sonnet 5.5 · учебный кейс eSIM

Одна пара, сначала обычная сессия OpenCode, затем сборка v10. Один исходный запрос из recording-guide.md и семь побайтово одинаковых файлов. Модель anthropic/claude-sonnet-5-5. Оценка авторская, открытая, по десяти заранее записанным критериям. Учитывались все предъявленные руководителю ответы в каждой сессии. Выбор пакета за 460 или 220 тысяч сам по себе баллов не добавляет.

Журнал OpenCode: обычный чат $0,11377, агент $0,48248, всего $0,59625. Списания по выписке провайдера и остаток счёта не проверены. При исходных $3 арифметический остаток составляет около $2,40. От первого до последнего зарегистрированного события около 5,2 и 4,9 минуты соответственно, включая паузы и восстановление; это не чистое время модели.

Сначала была неудачная попытка через Claude Pro с нулевым расходом, исключена из сравнения. Обе API-сессии потребовали продолжения после несовместимости ограничения шагов OpenCode с моделью. Обычный чат также столкнулся с сетевыми обрывами, агент — с ограничением вывода. Оба получили одинаковые нейтральные сообщения для восстановления и короткий итог с низким усилием рассуждения. Только агент запросил подтверждение выбора, после которого лимит длины одного ответа повысили для выдачи сводки. Вызовы помощников были ограничены ради бюджета. Это сравнение двух реальных бюджетных прогонов с восстановлением, а не слепой эксперимент или проверка полной конфигурации. Агент создал сводку, сообщил о незаполненном реестре и пропущенной проверке источников. Результат относится только к этому кейсу.
