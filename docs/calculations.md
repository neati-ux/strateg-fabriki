# Общие расчёты

`python tools/strateg.py calc economics --input inputs.json --output result.json` сохраняет входные данные и результат. Без `--output` вывод идёт в терминал. Готовый файл можно зарегистрировать в проекте как расчёт. Сохрани номера исходных утверждений в поле `basis` входного JSON, чтобы потом указать их в реестре.

- `economics`: `price`, `variable_cost_per_user`, `fixed_cost`, `paying_users`, `acquisition_spend`, `new_customers`. Деньги в одной валюте, расходы и цена за один период. Постоянные расходы указывай без затрат на привлечение. Безубыточность включает привлечение за этот период. Окупаемость предполагает неизменный вклад клиента за период и не учитывает отток. Для чувствительности добавь `"scenarios":{"Цена ниже":{"price":90}}`.
- `funnel`: `{"stages":[{"name":"Вход","count":40},{"name":"Активация","count":16},{"name":"Оплата","count":6}]}`. Все этапы относятся к одной группе. Результат показывает потери и конверсию от этапа к этапу и целиком.
- `retention`: `{"cohorts":[{"name":"Июнь","size":100,"retained":30},{"name":"Июль","size":20,"retained":12}]}`. Когорты не пересекаются и измерены в одном возрасте. Общий показатель взвешен по размеру когорт.

Доли выводятся от 0 до 1. Нулевой знаменатель даёт `null`. Расчёт не проверяет происхождение входных чисел.

`profile-table FILE --key id` проверяет UTF-8 CSV/TSV. Он показывает пропуски, дубли и строки неправильной ширины.

- `retention-change` сравнивает два периода по одинаковым сегментам. `segments` содержит `name`, `before` и `after` с полями `size`, `retained`. Эффекты состава и удержания внутри сегментов суммируются до общего изменения в процентных пунктах.
- `growth` принимает `initial_customers`, `price_per_period` и `periods` с `name`, `eligible_visitors`, `activation_rate`, `activated_to_paid`, `churn_rate`.
- `market-size` принимает `eligible_accounts`, `serviceable_share`, `obtainable_share`, `revenue_per_account_period`.
- `economics` с `period_churn` дополнительно считает LTV при постоянных вкладе и оттоке, а также LTV/CAC. Все доли задаются от 0 до 1. Значения модели являются сценариями на заданных предпосылках.
## Устойчивость выбора

`strateg calc decision-regret --input matrix.json` сравнивает варианты по одной метрике. Пример входа с условными значениями:

```json
{"metric":"прибыль за квартал, тыс. руб.","direction":"max","options":{"Текущий курс":{"слабый спрос":0,"сильный спрос":0},"Пилот":{"слабый спрос":-10,"сильный спрос":80},"Запуск":{"слабый спрос":-70,"сильный спрос":120}}}
```

Для каждого сценария программа находит лучший результат среди предложенных вариантов и считает разницу с ним для каждого варианта. Затем показывает наибольшую такую потерю по каждому варианту и все варианты с минимальной максимальной потерей. Для расходов используй `min`. Входы — целые числа в одинаковых единицах, например копейках. Одинаковые периоды и сопоставимость данных проверяет составитель. Вероятности сценариев для расчёта не нужны.
